# Sistema de Login e Cadastro em Java

## Descrição
Projeto desenvolvido para a disciplina de Desenvolvimento para Servidores I, com a finalidade de aplicar conceitos de programação orientada a objetos e integração com banco de dados.

## Funcionalidades
- Cadastro de usuários;
- Autenticação de login;
- Alteração de dados cadastrados;
- Exclusão de usuários.

## Tecnologias utilizadas
- Java;
- MySQL;
- JDBC;
- Java Swing;
- Maven.

## Banco de dados
O sistema utiliza o banco de dados MySQL, com uma tabela destinada ao armazenamento das informações dos usuários.

## Execução
A aplicação pode ser compilada por meio do comando:

```bash
mvn clean compile
```

Para iniciar o sistema, execute a classe `TelaLogin`.
